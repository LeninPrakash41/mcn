# MCN Student Pilot Kit

Everything needed to run a small pilot with students before a wide launch.

| File | For | What it is |
|---|---|---|
| [STARTER_GUIDE.md](STARTER_GUIDE.md) | Students | Install, a tour of MCN Studio, the language in five minutes, reading errors |
| [EXERCISES.md](EXERCISES.md) | Students | Eight exercises from first program to a full-stack app with AI |
| [solutions/](solutions/) | Facilitators | Reference solutions; exercises 1–7 include `test` blocks |
| [FACILITATOR_GUIDE.md](FACILITATOR_GUIDE.md) | Facilitators | Schedule, what to observe, metrics and follow-up |
| [FEEDBACK_FORM.md](FEEDBACK_FORM.md) | Students | End-of-pilot questionnaire |

The solutions, the exercise 3 error sequence and the starter-guide code are all
checked by `tests/test_pilot.py` on every push, so the exercises keep working
as MCN changes.
