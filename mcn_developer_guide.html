MCN Developer Reference

Welcome to the comprehensive developer manual for the Macincode Scripting Language (MCN). This guide covers all language syntax, standard library functions, and full-stack API capabilities you need to build business applications.

Keywords & Syntax

MCN is designed to be highly readable, borrowing familiar concepts from JavaScript and Python.

Keyword Description Example
var Declares a mutable variable. var count = 0
function Defines a reusable block of code. function calc(x) { return x * 2 }
if / else Conditional branching. if x > 10 { log("Big") } else { log("Small") }
for / in Iterating over collections. for user in users { log(user.name) }
use Imports external packages (e.g. ui, ai_v3). use "ui"
try / catch Error handling mechanism. try { failing_func() } catch { log("Error") }
and / or / not Logical operators (Python style). if valid and not expired

Syntax Example

// Variables and Logic
var status = "active"
var retry_count = 0

function check_status(user) {
    if user.role == "admin" and status == "active" {
        return true
    } else if retry_count < 3 {
        retry_count += 1
        return false
    }
    return false
}

Data Types & Collections

MCN relies heavily on Lists (Arrays) and Dictionaries (Objects). You can access dictionary properties using dot notation or bracket notation.

// Dictionaries (Objects)
var user = {
    "id": 101,
    "name": "Jane Doe",
    "preferences": ["email", "sms"]
}

// Property Access
log("User name: " + user.name)
user.role = "manager"     // Dynamically add properties

// Lists (Arrays)
var scores = [85, 92, 78]
scores[0] = 90            // Modify index
var first = scores[0]     // Access index

Standard Library Reference

MCN ships with over 100 built-in functions available globally without needing to import anything.

Strings

  • to_upper(str) / to_lower(str)
  • split(str, delimiter) / join(list, delimiter)
  • substr(str, start, end)
  • str_replace(str, old, new)
  • regex_find(str, pattern)

Arrays / Lists

  • len(array) — Returns item count
  • push(array, item) / pop(array)
  • map(array, func) / filter(array, func)
  • sort(array) / reverse(array)
  • unique(array) — Removes duplicates

Math & Logic

  • random() / random_int(min, max)
  • round(val) / ceil(val) / floor(val)
  • sum(array) / avg(array)

Example Snippet: Data Processing

var raw_data = ["apple", "Banana", "APPLE", "orange"]

// Clean and deduplicate data using stdlib
var clean_data = map(raw_data, to_lower)
var unique_fruits = unique(clean_data)

log("Total unique fruits: " + len(unique_fruits))

Database Connectivity

By default, MCN uses a zero-config local SQLite database (mcn_data.db). This lets you prototype instantly.

// 1. Default SQLite Querying
query("CREATE TABLE IF NOT EXISTS inventory (id INTEGER, item TEXT, qty INTEGER)")
query("INSERT INTO inventory VALUES (1, 'Laptop', 50)")

var items = query("SELECT * FROM inventory WHERE qty > 10")
log("Found " + len(items) + " items.")
Connecting to External Databases
For production, MCN natively supports external connections to PostgreSQL and MongoDB. The query() function automatically routes requests to your active connection. 
// Connect to PostgreSQL
connect_postgresql("db.internal.corp", "crm_db", "admin", "securePass!", 5432)

// Now queries execute on PostgreSQL!
var active_users = query("SELECT * FROM users WHERE status = 'active'")

// Connect to MongoDB
connect_mongodb("mongodb+srv://admin:pass@cluster.mongodb.net/", "logs_db")
var logs = query('{"collection": "events", "operation": "find", "filter": {"error": true}}')

AI & Natural Language

AI is a native primitive in MCN. You can invoke LLMs for raw text processing, or use the ai_v3 Natural Language Translation to generate MCN code dynamically.

use "ai_v3"

// 1. Direct LLM Execution
var response = run("gpt-4", "Summarize this customer feedback: The app is great but slow.")
log(response)

// 2. Natural Language to Code
var code_snippet = translate("create a list of numbers from 1 to 5")
log("Generated Code: " + code_snippet)

// 3. Retrieval-Augmented Generation (RAG)
var answer = rag("How do I reset my password?", support_docs)

UI Generation Engine

The ui package is MCN's full-stack superpower. It transforms your MCN script into a functional React 18 + Tailwind frontend, while keeping the logic securely on the MCN backend.

Component Usage
ui("page", title) Creates a new web page layout.
ui("button", label, backend_func) A button that triggers an MCN backend function on click.
ui("input", placeholder) A text input field.
ui("table", [headers]) A data grid. Use ui("bind_data", table, func) to populate it.
ui("chart", type, data) Generates a Recharts visual (e.g., "bar", "line").
ui("export", path) Generates the entire React codebase to the target folder.
ui("export_flutter", path) Generates a complete native Flutter Dart app to the target folder.

3. Web Playground & Interactive Simulators

The MCN Web Playground comes with three built-in simulator modules that speed up testing, prototyping, and debugging:

  • DB Explorer: Interactively inspect database tables and schemas generated by your MCN script. Write and execute SQL queries directly inside the console to view live tabular contents.
  • IoT Simulator: Simulate edge and sensor behaviors in real-time. Use interactive sliders and triggers to override values (e.g., temperature, motion) and trace command logs.
  • AI & RAG Inspector: Trace active AI model parameters, registry state, prompt history, and retrieval-augmented generation (RAG) search operations side-by-side.

Authentication & Payments (Stripe)

MCN makes standard SaaS infrastructure like user authentication and Stripe payments plug-and-play.

1. Automated Authentication (use "auth_auto")

By declaring use "auth_auto", MCN automatically creates a secure auth_users database table, registers backend register/login controller endpoints, and injects default /login and /register UI pages into the app registry. When you compile your app to React or Flutter, these pages are immediately generated and functional.

use "auth_auto"
use "ui"

// Default Login and Register pages are already injected behind the scenes!
ui("export", "./auth-dashboard-app")

2. Stripe Integration (use "stripe")

Call Stripe payment actions directly from MCN backend. If STRIPE_SECRET_KEY is set in the environment, MCN executes real transactions, otherwise, it falls back to mock responses in development mode.

  • create_payment_intent(amount, currency) — Generates a Stripe payment intent for custom checkout interfaces.
  • create_checkout_session(success_url, cancel_url, line_items) — Redirects users to Stripe-hosted checkout pages.
  • create_customer(email, name) — Registers a customer in Stripe.
  • create_subscription(customer_id, price_id) — Initiates recurring Stripe subscription billing.
use "stripe"

function checkout(data) {
    var session = create_checkout_session(
        "https://my-app.com/success",
        "https://my-app.com/cancel",
        [{"price": "price_H1A2B3C4", "quantity": 1}]
    )
    return {"url": session.url}
}

Full Business App Example

Here is an end-to-end example of a complete business application. This script handles the database, the backend APIs, and generates the entire React dashboard.

// --- admin_dashboard.mcn ---
use "ui"

// 1. Initialize Database
query("CREATE TABLE IF NOT EXISTS orders (id INTEGER, total REAL, status TEXT)")
query("INSERT INTO orders VALUES (1, 150.00, 'pending')")

// 2. Backend Logic (Controller)
function get_orders() {
    return query("SELECT * FROM orders")
}

function approve_order(data) {
    query("UPDATE orders SET status = 'approved' WHERE id = ?", (data.id,))
    return {"success": true, "message": "Order Approved"}
}

// 3. UI Generation (View)
var dashboard = ui("page", "Admin Dashboard")

// Create a stats card
var total_orders = len(get_orders())
var stat_card = ui("card", "Total Orders: " + total_orders)
ui("add_child", dashboard, stat_card)

// Create a data table
var order_table = ui("table", ["ID", "Total", "Status"])
ui("bind_data", order_table, "get_orders")
ui("add_child", dashboard, order_table)

// Add an interactive button
var approve_btn = ui("button", "Approve All Pending", "approve_order")
ui("add_child", dashboard, approve_btn)

// 4. Export the React Application!
ui("export", "./react-dashboard-app")

// 5. Or Export a Native Flutter Mobile Application!
ui("export_flutter", "./flutter-dashboard-app")

Deployment (React): Once you run the script, MCN generates a react-dashboard-app folder. Run npm start in that folder to view the Web UI. Start the MCN backend server via python run_mcn.py serve --file admin_dashboard.mcn.

Deployment (Flutter Mobile): For mobile, MCN generates a clean flutter-dashboard-app project structure. Navigate to that folder, configure dependencies, and run flutter run to launch the mobile app locally (communicating directly with the active MCN backend API server).

Packaging & Delivery

For deploying MCN scripts and runtimes in enterprise and production environments, MCN supports multiple packaging options:

  • Python Wheel Packaging: Build standard universal wheels using: 
    python3 setup.py sdist bdist_wheel
    This packages all core submodules, standard libraries, and Web Playground assets. Publish the output to private PyPI registries (e.g. AWS CodeArtifact, JFrog Artifactory) for deployment.
  • Docker Containerization: Deploy MCN as a service using the included Dockerfile. It builds an isolated, production-grade container containing the API execution server and playground.
  • VS Code Extension Packaging: Bundle visual editor support and language configs inside studio/vscode-mcn to a standard installation package using: 
    vsce package
