MCN Developer Guide

Architecture internals, compiler mechanics, static type checker, CLI tooling, and SDK bindings for software engineers.

Core Engine Architecture

MCN is engineered as a clean multi-pass execution engine. Source code traverses an indentation-aware lexer, a Pratt-style recursive descent parser, a compile-time static type validator, and a high-performance tree-walk runtime with built-in React and Flutter compilers.

1. Lexer Indentation stack & multiline ops
2. Parser Pratt precedence AST generation
3. Type Checker Gradual lattice validation
4. Evaluator Environment scopes & SQL DB
5. UI Bindings React & Flutter generators
Lexer: Tracks nesting levels _nesting_level across parentheses, brackets, and braces. Automatically handles multiline expression continuations.
Parser: Produces typed AST nodes carrying source locations (line, column) for precise diagnostics and language server protocols.
Type Checker: Static pass verifying parameter types, return signatures, variable reassignments, and compound operations.

CLI Tooling & Commands

The unified mcn CLI manages execution, static analysis, canonical code formatting, and web playground daemons.

mcn run <file.mcn> Execute Script

Executes an MCN script with sub-millisecond startup time and live performance telemetry.

$ python3 run_mcn.py run examples/sales_calendar.mcn
mcn check <file.mcn> [--strict] Static Type Check

Validates types, variable declarations, and return compatibility without executing runtime side-effects.

$ python3 run_mcn.py check script.mcn
mcn fmt <file-or-dir> [--write] [--check] Code Formatter

Reformats code to canonical 4-space indentation, standard operator spacing, and clean block structure.

$ python3 run_mcn.py fmt --write src/
mcn repl Interactive REPL

Opens an interactive prompt for rapid prototyping with persistent variable state and instant AI invocation.

$ python3 run_mcn.py repl

Standard Library & Native Modules

MCN ships with zero-dependency built-in packages imported with use "<name>".

use "db"
Embedded SQLite persistence and relational querying.
query(sql, params), insert(table, row), delete(...)
use "auth"
Enterprise JWT authentication and password hashing.
auth_create_token(claims), auth_verify_token(t)
use "ui"
Declarative UI compiler for React and Flutter.
ui("page"), ui("card"), ui("stat"), ui("table")
use "vector"
In-memory vector store for RAG & semantic search.
vector_upsert(id, text), vector_search(query, top_k)

React & Flutter UI SDKs

Deploy MCN components directly into your existing React or Flutter codebases using our production component libraries.

// React (@mcn/ui)
import { MCNCard, MCNStat, MCNAIPrompt } from "@mcn/ui";
export default function Dashboard() {
return (
<MCNCard title="Revenue">
<MCNStat label="Pipeline" value="$500,000" />
</MCNCard>
);
}
// Flutter (mcn_ui)
import package:mcn_ui/mcn_ui.dart;
class SalesPage extends StatelessWidget {
Widget build(BuildContext context) {
return MCNCard(
title: "Revenue",
child: MCNStat(label: "Pipeline", value: "$500,000"),
);
}
}
