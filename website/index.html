Language Overview

Reads Like English. Executes Like a Program.

MCN combines the clean, expressive syntax of Python and JavaScript with built-in language primitives for AI, databases, and UI declarations.

AI Language Primitives

AI is not an external SDK or REST call. It is a first-class language expression with native prompt string interpolation.

var patient = {"name": "John", "bp": "145/95"}
// Direct AI inference expression
var risk = ai("Assess triage urgency for: " + to_json(patient))
log("Patient assessed risk: {risk}")

Declarative UI DSL

Build production-ready interfaces using the unified ui(...) directive. Automatically compiles to React or Flutter.

ui("card", {"title": "Live Tickets"}, [
ui("stat", {"label": "Open", "value": 24}),
ui("table", {"data": tickets, "actions": ["Resolve"]}),
ui("button", {"label": "New Ticket", "variant": "primary"})
])

Zero-Setup Persistence

Query and mutate SQLite, PostgreSQL, or vector databases with single expressions. No ORM migrations or config files.

use "db"
// Query executes directly against embedded DB
var users = db_query("SELECT id, name, email FROM users WHERE role = 'admin'")
db_insert("audit_log", {"action": "admin_view", "count": users.length})

Expressive Syntax

String interpolation with {expression}, ternary operators, and JSON-native object/array manipulation.

var score = 85
var grade = score >= 90 ? "A" : score >= 80 ? "B" : "C"
// Nested interpolation
log("Score {score} earned Grade: {grade}")

Built-in Auth & RBAC

Secure your internal tools with enterprise-grade JWT generation, password hashing, and role validation in 2 lines.

use "auth"
var token = auth_create_token({"user": "nurse_01", "role": "staff"})
var session = auth_verify_token(token)
log("Authenticated role: {session.role}")

Reusable SI Packages

System integrators and teams can package domain logic once: use "accenture/healthcare" or use "stripe".

use "fintech/payments"
var charge = process_charge({"amount": 5000, "currency": "USD"})
log("Charge status: {charge.status}")

Language Architecture

MCN vs. Python

Why build a dedicated domain-specific language instead of standard Python? Python is a great general-purpose language, but building internal tools requires gluing 6+ fractured libraries. MCN bakes persistence, AI inference, and reactive multi-target UI directly into the language runtime.

Zero Dependency Hell

Python: Requires virtualenv, pip install fastapi sqlalchemy pydantic openai streamlit, and complex requirements.txt pinning.

MCN: Single binary. Native SQLite (use "db"), native AI, and UI directives work out of the box with zero external pip dependencies.

Dual React + Flutter Target

Python: Streamlit or Gradio are trapped in rigid web layouts and cannot compile to native iOS/Android mobile apps.

MCN: A single declarative ui(...) specification compiles simultaneously into production React (@mcn/ui) and native Flutter (mcn_ui).

Optimized for AI Coding Agents

Python: LLMs hallucinate wrong package versions, syntax quirks, and complex async event loop deadlocks.

MCN: Compact token footprint (70% fewer tokens), zero hallucinated imports, and instant self-healing via compile-time mcn check.
