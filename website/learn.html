Learn MCN in 15 Minutes

A simple, declarative scripting language combining database queries, AI agents, full-stack React/Flutter UIs, and backend workflows in zero-setup scripts.

1. Variables & Types 2. Functions & Control 3. Database & SQL 4. Native AI Primitives 5. Reactive UI Layouts 6. Workflows & Services
1

Variables, Literals & Optional Type Hints

MCN variables are declared with var. Types are gradually inferred, with optional TypeScript-style annotations for production compile-time static safety.

// Inferred Variables & Literals
var company = "Acme Corp"
var deal_size = 75000
var discount = 0.12
var is_active = true
// TypeScript-Style Optional Type Annotations
var user_email: str = "alex@acme.com"
var quota: int = 500000
var rates: list = [0.05, 0.10, 0.15]
// Objects & Dictionaries
var lead = {"name": "Sarah", "score": 94}
Key Rules:
  • Multiline continuation: Expressions automatically continue after +, *, and, ? across lines.
  • Gradual typing: Untyped variables act as dynamic types; typed variables are checked via mcn check.
  • Built-in types: str, int, float, bool, list, dict, any.
2

Functions, Conditionals & Loops

Functions support default parameters, return type validation, and concise 4-space indented or brace-enclosed blocks.

// Typed function with default argument
function calculate_roi(cost: float, margin: float = 0.25): float
var revenue = cost * (1.0 + margin)
return revenue
// If / Else & Ternary
if cost > 100000
log("Executive sign-off required")
else
log("Standard deal approval")
// Ternary assignment
var status = cost > 50000 ? "Enterprise" : "SMB"
// Loops & Collections
var deals = [45000, 82000, 120000]
var total = 0
// For loop
for deal in deals
total += deal
// Arrow Lambdas / Higher-order
var double_it = (x) => x * 2
log("Total Pipeline: $" + total)
3

Embedded Database (use "db")

Zero config, zero connection pool setups. Import the native db package to query and mutate SQLite databases using parameterized queries.

use "db"
// 1. Create table
query("CREATE TABLE IF NOT EXISTS leads (id INTEGER PRIMARY KEY, name TEXT, company TEXT, deal_size INTEGER, stage TEXT)")
// 2. Parameterized Insert (safe against SQL injections)
query("INSERT INTO leads (name, company, deal_size, stage) VALUES (?, ?, ?, ?)", ("Elena Rostova", "FinTech Cloud", 185000, "Closing"))
// 3. Query rows — returns JSON array of records
var active_leads = query("SELECT * FROM leads WHERE deal_size >= ?", (100000,))
log("High value leads found: " + active_leads.length)
4

AI Language Primitives (ai, rag, classify)

AI is built directly into the grammar. No OpenAI SDK instantiation, prompt engineering pipelines, or token stream parsing required.

// 1. Direct AI Generation
var summary = ai("Draft 3 discovery questions for a $150k CRM migration for Acme Corp")
// 2. Structured Classification
var urgency = classify("Database cluster latency exceeded 800ms", ["low", "medium", "critical"])
log("Assigned tier: " + urgency)
// 3. RAG Search across Vector Documents
var context = rag("What is our refund policy for enterprise annual contracts?", "knowledge_base")
// 4. LLM Extraction into JSON
var lead_data = extract("Hi, I am Sarah from HealthNet ($80k budget). Call me at 555-0199.", {"name": "str", "company": "str", "budget": "int"})
5

Reactive Multi-Target UI Layouts (ui(...))

Declare your visual interface in MCN. The engine compiles the layout to modern React components (@mcn/ui) for Web and Flutter widgets (mcn_ui) for iOS & Android.

use "ui"
// 1. Define Dashboard Components
var header_metrics = ui("container", [
ui("stat", {"label": "Target", "value": "$500,000"}),
ui("stat", {"label": "Pipeline", "value": "$740,000", "change": 18.4})
])
// 2. Define Interactive Table & AI Copilot
var table_panel = ui("card", {"title": "Sales Calendar"}, [
ui("table", {"data": active_leads, "columns": ["name", "company", "deal_size", "stage"]}),
ui("ai_prompt", {"placeholder": "Ask AI Copilot: Generate pre-meeting briefing..."})
])
// 3. Mount Page
var app = ui("page", "SalesPortal", "/", [header_metrics, table_panel])
6

Enterprise Services & Background Pipelines

Expose live REST endpoints, schedule cron tasks, and orchestrate multistep pipelines without setting up Express, Celery, or Docker containers.

// Instant REST Microservice
service LeadAPI
port 8080
endpoint "POST /leads/score"(req)
var lead = req.body
var score = ai("Score lead quality 1-100: " + to_json(lead))
return {"score": score, "status": "qualified"}
// Background Scheduled Job (Cron)
schedule "0 9 * * *"
log("Running daily 9 AM pipeline audit...")
